# Перевірка парної траєкторії вставки — 2026-09-02

Точка відкату до цих змін: Git commit `600ac00fac862ef465270fbc764ac8484d30dbf0`.
Перед відкатом збережіть нові зміни. Не застосовуйте reset --hard до робочої папки.

Виправлено:
- спільний індекс початку обходу обох контурів отвору;
- спільний центр повороту/дзеркалення парних профілів;
- спільна зміна початку замкненої парної траєкторії;
- збереження парних точок при повторному призначенні в DXF-панелі;
- однакова кількість етапів підходу/повернення, включно з нульовими рухами;
- готові парні маршрути проходяться одним контуром: довільний поділ навпіл
  не повинен розділяти отвір;
- при виборі вставки зі збірки для різання отвори перебудовуються з її
  зовнішніх контурів та параметрів прутів.

Перевірки: `node --test tests/paired-insert.test.js`, `node --check src/main.js`,
`pnpm run build`. Для додаткового тесту початкового NC задайте змінну середовища
`FOAMCUT_TEST_NC` шляхом до `oc 8 wing 2.10.25.nc`. Сам файл у репозиторій не копіюється.

Конкретний перевірений приклад: початкове крило, вставка 150%, зміщення кореня 0,
довжина вставки 400 мм; відстань між площинами кареток 500 мм, проміжки по 50 мм;
блок у площині профілю 600 × 600 мм; відступи X=120, Y=23 мм; вхід зліва,
підхід 10 мм, компенсація ввімкнена, орієнтація як у джерелі.
Максимуми маршруту: X=576.081, Y=87.042, A=481.625, Z=71.348 мм.
Ці числа не є автоматичною рекомендацією для іншої збереженої збірки.

Важливо: старий згенерований NC не виправляється сам. Потрібно повторно вибрати
вставку для різання (або створити її заново), перевірити встановлення й згенерувати NC.
Стара збірка з помилковими зовнішніми контурами потребує повторного створення вставки.
Перевірка діапазонів координат не доводить відсутності зіткнень чи правильності
пропалу. Фактичну посадку прута слід перевірити на пробному зразку.
Реальний станок не підключався; інтерактивна перевірка інтерфейсу не виконувалася.
